# 视觉方向与风格迁移

## 目录

1. 决策顺序
2. 风格族
3. 参考图风格迁移
4. 逐页 storyboard
5. 跨风格精品底线

## 1. 决策顺序

1. 先识别用途：现场演讲、发布、汇报、阅读、教学或答辩。
2. 再判断素材：是否有高质量摄影、产品图、人物图、界面、图表或品牌规范。
3. 有参考图时优先风格迁移；用户点名风格时按点名方向；其余才自动选择。
4. 自动选择时只选一个风格族，不把多套 design system 拼贴在一起。
5. 颜色不是决策起点。先定影像、字体、网格和节奏，再定色板。

## 2. 风格族

| 风格族 | 适合 | 核心语法 | 避免 |
|---|---|---|---|
| `cinematic-editorial` | 发布、人物、品牌故事、纪念 | 满幅摄影、强明暗、少字、大尺度变化 | 通用星空、每页暗底、照片平铺 |
| `bright-luxury` | 高端产品、生活方式、地产、服务 | 高调摄影、浅中性色、大留白、精细字体 | 大面积金色、粗重阴影、满页边框 |
| `swiss-minimal` | 战略、品牌系统、产品概念 | 网格、左对齐、高对比字号、单一几何母题 | 空洞极简、每页只换一句话 |
| `editorial-magazine` | 作品集、旅行、文化、品牌内容 | 非对称编排、图片裁切、编辑标题、细节栏 | 每页一模一样的图文分屏 |
| `organic-natural` | ESG、健康、食品、环保、教育 | 自然光、低饱和色、材质细节、柔和形状 | 卡通化绿色、滥用叶子图标 |
| `tech-industrial` | 工程、制造、航天、AI 产品 | 真实设备/界面、精密网格、局部高亮、数据叠加 | 蓝紫渐变墙纸、星点、假 HUD |
| `consulting-data` | 咨询、研究、季报、决策 | 结论式标题、图表、逻辑结构、高密度但严格对齐 | 每页四卡片、彩虹色、无结论的图表 |
| `cultural-contemporary` | 文旅、历史、东方品牌、艺术 | 当代网格+文化材质、克制书法/纹理、大留白 | 古风贴纸、满页印章、假文物 |

## 3. 参考图风格迁移

先写“参考 DNA”，再写页：

- **影像**：照片占比、景别、裁切、色温、对比度、是否统一调色。
- **排版**：标题尺度、字重、行宽、对齐、文字占比。
- **构图**：主体位置、留白、不对称程度、图文关系。
- **节奏**：满幅页、分屏页、数据页、低密度页如何交替。
- **细节**：线条、页码、标签、阴影、圆角的强度。
- **不复制**：水印、商标、带版权原图和与用户主题无关的文字。

风格迁移是复用“视觉语法”，不是复制颜色。参考图是暗色不代表成品必须暗色；若用户明确只要其构图和精致度，可保留语法并更换色调。

## 4. 逐页 storyboard

在 DESIGN.md 中为每页写一行：

```text
P1 | 封面 | 满幅产品特写 | 让观众感到精密与可靠
P2 | 命题 | 大留白+一句结论 | 建立问题
P3 | 证据 | 数据图+局部图片 | 证明规模
...
```

规则：

- 相邻两页不使用完全相同的骨架。
- 8 页以上至少 4 种页型；至少 1 张主视觉高潮页和 1 张低密度呼吸页。
- 卡片宫格页不超过 20%；卡片只用于真正并列的信息。
- 图片优先按真实宽高比排版，不先画图框再强塞素材。

## 5. 跨风格精品底线

- 一页一个第一焦点；标题、证据、注释权重不得相等。
- 配图必须与结论相关、清晰、不拉伸，且不压住人脸、产品主体或 Logo。
- 文字不得产生孤字折行、百分号/单位拆分、截断、重叠和密集小字。
- 用字号、网格、留白和图片建立层级；不用无意义英文、黄金细线或圆角卡片假装设计。
- 整套保持同一视觉世界，但页型、图片尺度和信息密度必须变化。
- 必须完成平台截图审查的有界返工；静态 QA 通过不代表视觉通过。
