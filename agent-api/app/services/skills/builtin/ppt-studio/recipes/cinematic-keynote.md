# 配方：电影感 / 发布会片（高级感默认）

对标：品牌发布会、SpaceX 风格 keynote、SLAM / ESPN The Magazine 封面故事。  
**不是**咨询报告，也不是「藏青顶栏 + 白底正文」的政务/球队官网模板。

人物志、品牌、产品、纪念、路演，只要用户没点名「汇报风 / 简洁文档」，**默认走这一份**。

## 一句话

照片是页面本身。字叠在图上。品牌色只点一下。翻页，字自己进来。

## 失败标本（2026-08-13 真机，禁止再做）

用户说「说不出哪里不对」，拆开就是下面这套：

- 11 页同一壳：左边深藏青字，右边一张生成的星空/雾气渐变，当装饰条
- 没有一张真照片（办公室、产品界面、城市夜景、人、硬件都不行，用墙纸充数）
- 标题折成「一场没有发布会的发 / 布」「双双拉 / 满」——最后一字孤行
- 数字挤在一起还和脚注重叠
- 几乎每页右下角「来源：××报道」——研报，不是发布会

这叫**深色科技模板**，不叫电影感。  
SpaceX / TCXP 那种感觉是：**一张与主题有事实关系的真图铺满 + 很少的字叠上去 + 每页换构图 + 安静**。它不是“随便找一张太空壁纸”。

产品/模型发布同样适用。找不到人像就下官网界面、机房、城市夜景、硬件特写；再没有，就整页近黑 + 一个巨号数字或一句金句，**不要发明右半屏星空条**。

## 色与光

- 底：近黑 `#07080A` / `#0B0B0D`，或照片本身。不要大面积纯白内容区。
- 字：暖白 `#F4F1EA`。弱信息 `#9A968C`。
- 点缀：一色即可（金 `#C9A227` / 品牌主色 / 火焰橙），全 deck **只占约 5–8%**——一条细线、一个数字、一句 kicker。
- **禁止**把品牌色做成每页 80–120px 高的顶栏。那是模板，不是设计。
- 照片可压一层半透明黑 `opacity: 0.35–0.55`，保证字可读；不要整页灌成同一块藏青滤镜。

## 字体

```yaml
fontFamily: {latin: "Helvetica Neue", ea: "Microsoft YaHei"}
```

标题可略加大字距（`letterSpacing: 2–6`）。不要 Arial / Calibri / 宋体。

## 构图（12 页至少换 4 种）

| 骨架 | 用法 |
|------|------|
| 满幅图 + 左下/左中大标题 | 封面、阶段高潮、收束 |
| 左 55% 图齐边裁切 + 右暗底字 | 人物/产品特写 |
| 整页一句 40–64pt 金句，几乎无其它 | 节奏停顿 |
| 一个 96–128pt 数字 + 一行解释 | 纪录/MVP/融资额 |
| 暗底细字时间线（不是表格墙） | 履历 |
| 回封面的暗场 + 一行告别 | 末页 |

**禁止连续 3 页同一顶栏。**  
**禁止 2×2 / 3 列圆角卡。** 要并列信息：用字号差 + 细线，或拆成两页。

## 图

- 人物/产品类至少 **6** 张真图；其中 **≥3 页满幅**（`bounds` 贴齐画布 `[0,0,960,540]`）。
- 图不要放进浅底/圆角卡片。不要「东方 IC」水印图当英雄图——换一张。
- **默认不使用星空 / 星云 / 雾气 / 粒子渐变。** 只有航天/天文主题可用一张真实任务、地球或火箭照片；生成壁纸、星点背景永远不算图，也不能拿来当封面垫底。
- 字不要压脸。主体在右，字在左，或反过来。
- 标题一行写不下就改短。禁止「发 / 布」「拉 / 满」这种孤字折行。

## 文案密度

一页主句 ≤ 18 个汉字，正文 ≤ 3 行。写长了就删，不要缩小字号硬塞。  
数字单独拿出来做一页，比塞进段落更贵。

## 动画（默认开，导出已支持）

WASM 导出**会**把页级 `animations` 写进 PPTX。不要再假装「加了也出不来」。

默认语法（每页抄这个，再改 elementId）：

```yaml
# 背景图、暗底色块不要做动画
# 第一组：翻页自动播（afterPrevious 作第一条 = 进页即播）
animations:
  - elementId: kicker
    effect: fade-in
    trigger: afterPrevious
    durationMs: 400
  - elementId: title
    effect: fade-in
    trigger: withPrevious
    delayMs: 80
    durationMs: 550
  - elementId: stat
    effect: float-in
    direction: up
    trigger: afterPrevious
    durationMs: 500
```

铁律：

1. 人物/品牌/路演/纪念：**每页都要有 `animations`**，除非该页只有一张满幅图、没有任何字。
2. 每页 **1–2 组**。第一组进页即播。第二组（可选）`onClick`——只给「再揭示一个数字」。
3. 只用 `fade-in` / `float-in` / `wipe-in`。禁止 `spin` / `teeter` / `grow-shrink` / 彩虹 `color-pulse`。
4. 翻页效果沿用导出默认 **fade**，不要改成 none。
5. 不要一页 8 个元素逐条飞入。那是课堂课件，不是发布会。

工作汇报 / 学术 / 教学：默认不加页内动画，只留翻页 fade。
