# 配方：商业路演 / 方案 / 融资介绍

适用：BP 精简版、合作方案、产品推介、招商。

## 默认参数

- 页数：8–10（完整 BP 可 12–15，需用户同意）
- 场景：`reference/slides_categories/business-plan.md`
- 可参考：`reference/design_system/02_business` / `consulting`

## 推荐页序（经典节奏）

1. 封面：一句话价值主张  
2. 问题  
3. 解决方案  
4. 产品/演示（尽量真界面截图）  
5. 市场或受众  
6. 商业模式  
7. 竞争差异（表格式，忌空喊第一）  
8. 进展与里程碑  
9. 团队  
10. 诉求 / Call to action  

## 配图

- 产品 UI、场景、客户环境优先真图
- 无真实客户 logo 授权时不要伪造 logo 墙

## 不要

- 无数字的「巨大市场」空话
- 每页相同图标+三列卡
- 超过一页的小四号法律长文（改附录或口头）
