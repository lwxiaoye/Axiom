# 配方：人物志 / 球星 / 创始人深度介绍

适用：运动员、企业家、历史人物、团队成员介绍等「以人为主角」的 PPT。

## 默认参数

- 页数：10–12（用户指定优先）
- 画布：960×540
- 风格：**默认暗色电影感**（先读 `recipes/cinematic-keynote.md`）。只有用户明确说「浅色 / 文档 / 汇报」才改浅底。
- 场景文档：`reference/slides_categories/brand-creative.md` + cinematic-keynote；数据页可借 `analysis-decision.md` 的克制，但不要借它的卡片墙

## 推荐暗色 token（可直接用）

```yaml
theme:
  colors:
    primary: "#C9A227"   # 点缀金，可按品牌替换
    accent: "#7B2D8E"
    text: "#F2F0EA"
    muted: "#9A968C"
    bg: "#0B0B0D"
    panel: "#141416"
    line: "#2A2A2E"
  textStyles:
    title:
      fontFamily: {latin: "Helvetica Neue", ea: "Microsoft YaHei"}
      fontSize: 36
      color: "$text"
      bold: true
    body:
      fontFamily: {latin: "Helvetica Neue", ea: "Microsoft YaHei"}
      fontSize: 16
      color: "$text"
      lineHeight: 1.45
```

装饰：细金线 `shape rect` 高 3–5px、宽 48–64；页码小字 `letterSpacing: 2`。  
**不要**整页霓虹渐变、不要圆形头像墙贴满。  
**不要**球队配色顶栏（藏青条 + 橙线 + 白底正文）——那是官网新闻稿，不是人物志。品牌色只点缀数字和 kicker。

## 推荐页序

| # | 页 | 要点 |
|---|----|------|
| 1 | 封面 | **满幅**赛场图 + 压暗 + 姓名 + 一句定位 + 年份跨度。标题 fade-in |
| 2 | 目录/阅读导航 | 暗底，少字，3–6 项；不要 2×3 彩条编号卡 |
| 3 | 档案 | 半身齐边大图 + 右侧 4–6 个关键字段（不是浅底信息卡） |
| 4 | 早年/出身 | 叙事短段落叠在图上，或左图右字 |
| 5 | 生涯时间轴 | 横向节点，避免密密麻麻表格 |
| 6–8 | 关键阶段 | **每页一个阶段一张满幅图** + 一句评价 + 一个数字。构图不许与上一页相同 |
| 9 | 纪录 | 一个巨号数字一页，或两三个数字纵向排；禁止四宫格卡片 |
| 10 | 技术/风格 | 优势 vs 限制，各 3–4 条短句，忌空话 |
| 11 | 遗产与告别 | 暗场 + 一句金句，可回封面那张图 |
| 12 | 来源 | 链接到公开资料 |

## 配图

- 至少 **6** 张与人物直接相关的真实照片（动作、肖像、赛场/现场）
- 其中 **≥3 页满幅**（图片 `bounds: [0, 0, 960, 540]`），字叠上面
- 优先 Wikimedia / 官方新闻图 / 用户上传；下载到 `media/` 再引用
- 封面图压暗 0.35–0.55，保证标题可读；不要整页同一块藏青滤镜
- 每页写 `animations`（见 cinematic-keynote）：进页 fade/float，不要等用户点了才动

## 文案

- 用具体事件与数字，少用「传奇」「王者」堆砌
- 争议或短板可以写，显得专业
- 进行中赛季数据加「约 / 截至公开资料」

## 不要

- 只有 Wikipedia 条目复制 + 项目符号
- 每页相同三列圆角卡、四宫格纪录卡、左侧彩条编号
- 每页一条品牌色顶栏 + 白底正文（报告模板）
- 照片装在浅底卡片里
- 无图的 12 页纯字
- 整本没有 `animations`（人物志默认要入场）
