## 1. 三层组成

```text
浏览器（Vue 3 + Vite，src/）
  ├─ /login                      登录 / 自助注册（views/system/loginmini）
  ├─ /center/chat                主对话（views/peopleCenter/pages/ChatPage.vue）
  ├─ /center/chat/campus         校园百事通    ┐
  ├─ /center/chat/ppt            演示文稿助手  ├ BuiltinHarnessRunPage.vue，按 preset 区分
  ├─ /center/chat/interview      面试助手      ┘
  ├─ /center/agent               智能体广场（只列上面三个预置智能体）
  ├─ /center/skill               Skill 广场
  ├─ /center/knowledge           我的知识库（views/knowledge/）
  ├─ /center/files               我的文件
  ├─ /center/models              个人模型配置（可选的个人 API Key）
  └─ /admin                      管理配置（AdminConsolePage.vue，仅管理员）

agent-api（FastAPI，agent-api/app/，前缀 /agent-api）
  ├─ api/router.py               主对话 Run / Thread / 队列 / 记忆 / 模型列表
  ├─ routers/                    知识库、Skill、文件、工作文件夹、工具网关审批、
  │                              平台配置（对话模型名册 / 向量 / 重排 / 联网搜索）、校园百事通发布、审计
  ├─ services/agent_harness/     主对话内核（orchestrator / model_driver / kernel / run_store / research）
  ├─ services/chat/              受理、回合决策、内置助手策略、工具实现（tools/）
  ├─ services/knowledge/         知识库入库、向量 / 关键词 / 混合检索、重排、联网搜索、检索日志
  ├─ services/skills/            Skill 目录、取包桥接、内置 ppt-studio
  ├─ services/sandbox/           bash 沙箱适配（opensandbox 默认；local / e2b / sealos 备选）
  ├─ services/files/             用户文件、文档解析、产物交付、存储（local / MinIO）
  ├─ services/platform/          模型连接名册、密钥服务、平台配置
  ├─ services/memory/            长期记忆与个性化
  └─ worker.py                   后台 Worker：租约 PostgreSQL Job，执行 Run 并持久化事件

auth-api（FastAPI，auth-api/app.py + store.py，前缀 /api → /sys/*）
  └─ 单管理员 + 自助注册 + 个人资料；图形验证码；Token 校验；SQLite 卷

数据
  ├─ MySQL（ai_boot）          业务域：会话、消息、知识库与切片正本、Skill、文件、app_info 上架记录、平台配置
  ├─ PostgreSQL               Runtime 域：Run / Job / 事件 / 计划 / 工具结果 / 用量审计；LangGraph checkpoint 独立库
  ├─ Qdrant                   知识库向量（集合按 模型+维度 命名）
  └─ SearXNG                  联网搜索（docker-compose.server.yml）
```

前端通过同源 Nginx（生产）或 Vite 代理（开发）把 `/api`、`/upload` 转到 auth-api，`/agent-api` 转到 agent-api。

## 2. 模块边界与事实源

| 模块 | 代码入口 | 说明 |
| --- | --- | --- |
| 主对话 Harness | `services/agent_harness/`、`services/chat/`、`api/router.py` | 唯一 Agent Loop；Standard / Plan / Research 三个 Profile 共用；细节见 Harness 规范 |
| 内置助手 | `services/chat/builtin_assistants/{campus_services,presentation,interview}/`；前端 `views/peopleCenter/builtinAssistants/` | 只声明身份、提示词与工具边界，不另起执行内核 |
| 广场上架与 ACL | `services/chat/builtin_app_access.py`；`app/main.py::_seed_builtin_app_catalog` | `app_info` / `app_role` / `app_dept` 由启动期幂等补种，`GET /chat/builtin-apps` 只返回当前用户可见项 |
| 校园百事通发布 | `campus_services/config_service.py`（草稿 → 校验 → 发布 / 回滚）、`domain_policy.py`（官网白名单）、`runtime_service.py`（每次运行的配置快照） | 管理页 `/admin` 「校园百事通」tab；未发布时前台明确不可用 |
| 知识库 | `services/knowledge/`、`routers/knowledge.py`；前端 `views/knowledge/` | 切片正本 MySQL `agent_knowledge_chunk`（ngram 全文）+ Qdrant 向量；`VECTOR / KEYWORD / HYBRID` 检索 + 可选重排；分段编辑、重建；检索日志与 `/bases/{id}/analytics` |
| 知识库权限 | `knowledge_base_service.permission_for`、`/bases/{id}/acl` | OWNER / EDITOR / VIEWER；管理员无旁路，不可见即 404 |
| Skill | `services/skills/skill_catalog.py`、`routers/agent_skill.py`；前端 `SkillSquare.vue` | 表 `agent_skill` / `agent_skill_version`；直接编写或 zip 导入，版本化；个人技能按用户隔离，管理员可分发 / 撤回 |
| 工具与网关 | `services/chat/tools/`、`services/gateway/tool_gateway.py`、`routers/gateway.py` | 知识库检索、联网搜索、bash、文件、浏览器、`use_skill`、`ask_user_choice`、记忆；敏感工具 `needs_approval` → `/gateway/approve|reject` |
| 沙箱 | `services/sandbox/factory.py` | `SKILL_SANDBOX_PROVIDER` 选 provider；生产用 opensandbox（`deploy/opensandbox-api/`） |
| 文件 | `services/files/`、`routers/files.py`；`routers/workspace.py` 是会话工作区（沙箱草稿），不是我的文件 | 我的文件（文件夹、版本、恢复）、会话附件、工作文件夹绑定 Thread（`workspace_folder_id`） |
| 模型配置 | `services/platform/model_connection.py`、`routers/model_connection.py` | 平台名册（多条，OpenAI / Anthropic 地址）对全员生效；个人覆盖 `/model-connection/personal` 可选 |
| 向量 / 重排 / 联网搜索 | `routers/embedding_config.py`、`routers/rerank_config.py`、`routers/platform_config.py` | 密钥 Fernet 密文入库（`connectors/crypto.py`，主密钥 `CONNECTOR_SECRET_KEY`） |
| 记忆 | `services/memory/`、`api/router.py` 的 `/memories*`、`/personalization` | 候选 → 治理 → 写入；前端 `MemoryDrawer.vue` |
| 连接器 | `services/connectors/`、`routers/connectors.py` | GitHub / Gmail / Outlook / IMAP 的授权与资源范围；主对话入口开关 `mainChatFeatureVisibility.ts` 目前为隐藏 |
| 认证 | `auth-api/app.py`；agent-api `core/auth.py` | agent-api 用 `X-Access-Token` 回源 auth-api `/sys/user/getUserInfo`，`AUTH_TOKEN_CACHE_TTL_SECONDS=0` 时每次重校验 |
| 迁移 | `agent-api/migrations/`（`-n mysql` / `-n runtime`） | 两条 Alembic 链；规则见 [`../agent-api/migrations/README.md`](../agent-api/migrations/README.md) |

## 3. 数据所有权

| 数据 | 所有者 | 不要这样做 |
| --- | --- | --- |
| 用户、角色、密码、Token | auth-api（SQLite 卷 `axiom_auth_data`） | agent-api 自行维护第二套身份 |
| 会话、消息、附件 | agent-api / MySQL | 前端或聊天正文保存第二份状态 |
| Run、Plan、事件、工具结果、用量审计 | agent-api / Runtime PostgreSQL | 用 MySQL 或前端推导终态 |
| 知识库、文档、切片正本、ACL | agent-api / MySQL + Qdrant 索引 | 绕过 ACL 直接查 Qdrant |
| Skill 目录与版本 | agent-api / MySQL；内置包文件树在 `services/skills/builtin/` 磁盘 | 把内置包 zip 复制进库 |
| 校园百事通草稿、发布版本、运行快照 | `campus_services/config_service.py` | 临时绕过未发布检查 |
| 用户文件与版本 | `services/files/user_file_service.py` + 存储后端 | 只以沙箱路径当交付 |
| 长期记忆 | `services/memory/` | 模型直接写库或跨用户召回 |
| 平台配置与密钥 | `agent_platform_config`（密钥 Fernet 密文） | 明文入库、写进 `VITE_*` 或提交 Git |

## 4. 安全边界

- `/center/*` 与 `/admin` 保持登录保护；管理员判定在 agent-api `core/auth.py::is_admin`（用户名 `admin` 或角色含 `admin`），角色来自 auth-api 回源结果，不信任浏览器传入的角色或部门。
- 管理员没有隐私旁路：用户的会话、文件、知识库与个人技能对管理员不可见（不存在即 404）。
- 模型只能调用本轮 Tool Registry 实际注册的工具；外部副作用与危险动作经工具网关审批（`approval.required` 事件 → `/gateway/approve|reject`）。
- 沙箱默认隔离网络；联网搜索、网页读取、浏览器与连接器的出站请求共用 `gateway/mcp_client.py` 的公网地址校验（`PinnedPublicTransport`），禁止私网与环回地址。
- 所有模型、向量、重排、联网搜索密钥只以 Fernet 密文入库；`AXIOM_CONNECTOR_SECRET` 变更后旧密文解不开，需在管理页重填。
- 校园百事通固定只读工具 `search_knowledge` / `search_web`，联网搜索强制官网域名白名单；客户端传入的知识库、Skill 或模式参数不能越过发布快照。
