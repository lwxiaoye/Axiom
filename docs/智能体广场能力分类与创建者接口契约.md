# 智能体广场能力分类与创建者接口契约

2026-09-11 核对范围为本仓库的前端分类/展示逻辑与迁移脚本；没有读取生产业务数据或独立 Java 仓库。

## 能力分类

`app_info.app_category` 只允许下列稳定值：

`communication`、`document_knowledge`、`data_table`、`content_creation`、
`planning_structure`、`developer_automation`、`image_multimedia`、`other`。

广场前端不根据名称或描述推测分类；后端返回的空值或未知值统一回退到
`other`。`agent-api/scripts/agent_market_category_manifest.json` 保存的是该次迁移的 23 条目标清单，不能据此认定当前系统仍只有 23 条应用；实时目录和分类数据以业务接口为准。

迁移脚本默认仅校验：

```bash
cd agent-api
python scripts/migrate_agent_market_categories.py
```

审核解析出的稳定 ID 和分类数量后，由数据环境负责人执行：

```bash
python scripts/migrate_agent_market_categories.py --apply
```

脚本在事务开始前备份旧值；名称缺失、重复、回读不一致，或仍存在使用旧分类的上架应用时，
整个事务终止且不停用旧字典项。

## 创建者信息

约定 `GET /api/app/appInfo/my/all/list` 每条应用可追加以下字段；当前前端已经消费，Java 是否已回填须在对应服务验证：

```ts
createByName?: string;
createByAvatar?: string;
```

- `createByName` 是当前创建者真实姓名，不是登录账号。
- `createByAvatar` 是已有静态文件地址，与系统其他用户头像字段格式一致。
- Java 列表查询必须一次性收集 `create_by`，再批量查询用户表并回填；禁止前端或后端逐卡查询。
- 前端按 `createByName -> createBy_dictText -> createBy` 查找可读名称，过滤疑似长数字 ID/UUID；没有可读值时显示“未知”。已有用户资料匹配创建者身份时可补全实名和头像，不把不匹配用户的资料贴到应用上。
- 头像缺失或加载失败时使用名称缩写：中文取首字，英文/数字最多两位，未知为 `?`。对应逻辑在 `src/views/peopleCenter/agentMarketCapabilities.ts`。

这两个字段是向后兼容的可选字段。当前仓库只包含 Vue 前端与 agent-api，Java 列表查询的实现需在对应 Java 仓库完成。
