日期：2026-09-17。对象：当前 Windows 工作区源码、本地依赖和本机 AXIOM Docker 栈。未连接历史部署；未将工作区中的归档目录作为项目。报告反映本次检查，不是“所有 bug 已经找到或修复”的证明。

## 1. 当前可以运行到哪里

Vue 前端已构建并运行于 `axiom-frontend`，宿主地址 http://127.0.0.1:3200/。Docker 显示 `127.0.0.1:3200->80`，容器健康。浏览器实际呈现登录页及验证码，无加载 error/warn。首页、深层路由和入口 JS/CSS 返回 200；隐藏环境文件返回 403，不存在的静态资源返回 404；认证及 Agent 代理对未登录请求均返回 401。

新增前端镜像、Nginx 路由和 Compose 服务；已更新本项目 auth-api、agent-api、agent-worker 镜像及容器。没有重启数据库和其他项目容器。后台运行时健康检查通过，但尚未完成浏览器认证后的全业务验收、真实模型问答或真实校园知识检索。

账号默认 `admin`。本地独立随机密码保存在被 Git 忽略的 `deploy/local/.env` 的 `AXIOM_ADMIN_PASSWORD`，本文不记录密码。旧默认密码不可继续依赖。

模型没有随本项目本地部署：配置指向的本机 3001 网关在检查时不可用，聊天模型和用户模型凭据记录均为 0。嵌入模型有 1 条配置不等于服务可调用；Qdrant 集合为空。校园配置/发布和工作流应用记录为 0。源码包含校园、PPT、面试三个内置助手入口，另有通用聊天；入口数量不等于可用 Agent 数量。
