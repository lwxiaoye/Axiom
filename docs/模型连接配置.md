# 模型连接配置

管理员登录后，打开左侧「我的文件」下方的「模型配置」，或访问 `/center/models`。

填写支持 OpenAI Chat Completions 协议的 API 基础地址、API Key 和模型 ID。
地址通常以 `/v1` 结尾；填入完整 `/chat/completions` 地址时会自动去掉末尾接口路径。
点击「测试连接」会用当前表单发送一条短请求，不保存配置，可能产生少量模型费用。
点击「保存配置」才会将配置写入数据库。

配置只作用于当前账号。启用后，主对话模型选择器提供所填模型；修改影响后续请求，已开始的任务保留当前任务内的连接信息。
关闭后回退到原有网关与账号 Key 配置。校园助手仍遵守已发布配置、模型选择与 ACL 约束，不会绕过发布门禁。
测试成功仅证明普通 Chat Completions 请求可用；工具调用、视觉、Responses 等能力仍取决于服务商与模型支持情况。

密钥使用既有 Fernet 加密服务保存在 `agent_platform_config` 中，接口只返回是否已配置。
API 与 Worker 必须使用同一个稳定的 `CONNECTOR_SECRET_KEY`（本地 Compose 已共享该值）。
留空密钥表示保持原密钥；修改请求地址必须重新输入密钥。不要把服务商密钥写入前端环境变量或 Git。

配置和测试接口均要求管理员身份；允许管理员连接本地/内网模型服务。Docker 中的 `localhost` 指容器自身，宿主机服务请使用 `host.docker.internal`。
