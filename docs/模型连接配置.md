# 模型连接配置

2026-09-19 按 `agent-api/app/services/platform/model_connection.py`、`routers/model_connection.py` 与 `src/views/peopleCenter/pages/AdminConsolePage.vue`、`ModelConfigPage.vue` 核对。

对话模型分两层：**平台名册**（管理员配置，对所有登录用户生效）和**个人覆盖**（任何用户可选填，优先于名册）。学生不需要自带 API Key。

## 1. 平台名册（管理员，`/admin` → 对话模型）

- 名册最多 32 条（`MAX_MODELS`），每条独立：名称、OpenAI 地址（`base_url`）、Anthropic 地址（`anthropic_base_url`）、模型 ID、API 密钥、启用开关。两个地址至少填一个；当前请求走 OpenAI 兼容 Chat Completions，有 OpenAI 地址用它，否则用 Anthropic 地址。
- 地址通常以 `/v1` 结尾；填入完整 `/chat/completions` 地址时自动去掉末尾接口路径。
- 「设为默认」决定 `default_id`；卡片可拖动排序；「测试连接」用当前表单发一条最短请求，不保存、可能产生少量费用；「测速」对名册里每条可用模型各发一次并把 `latency_ms` 记回名册。
- 「启用平台模型」总开关关闭后回退到 `NEWAPI_BASE_URL` 指向的旧网关，已添加的模型仍保留。
- 主对话模型选择器（`GET /agent-api/models`）列出名册里已启用的模型；校园百事通仍只用发布快照里固定的那一条，不受选择器影响。

接口（`/agent-api` 前缀，需管理员）：`GET /model-connection`、`PUT /model-connection`（整份名册 `{enabled, default_id, entries[]}`）、`POST /model-connection/test`（单条）、`POST /model-connection/test-speed`。

## 2. 个人覆盖（任何用户，`/center/models`）

侧栏底部「模型配置」。填一条 OpenAI 兼容连接（地址、模型 ID、密钥）并启用后，本人对话优先用它；关闭即回到平台默认模型。修改只影响后续请求，已开始的 Run 保留本次连接。

接口：`GET/PUT /model-connection/personal`、`POST /model-connection/personal/test`。返回体附带 `platform: {configured, model, models}` 说明平台名册当前状态。

## 3. 存储与密钥

- 名册存 `agent_platform_config` 的 `model_connection` 行；个人覆盖存 `user_model_connection:<sha256(user_id)[:40]>`。旧的单条平台连接与更早的按管理员 user_id 存法在读取时原地收成名册条目，管理员再次保存才写成新形状。
- 密钥用 `connectors/crypto.py` 的 Fernet 加密后入库（`api_key_cipher`）；接口只返回 `has_api_key`，不回显明文。留空表示保持原密钥；改了地址必须重新输入密钥。
- API 与 Worker 必须使用同一个稳定的 `CONNECTOR_SECRET_KEY`（compose 由 `AXIOM_CONNECTOR_SECRET` 注入）；换了它旧密文解不开，需在页面重填。
- 不要把服务商密钥写进前端环境变量或 Git。Docker 里的 `localhost` 指容器自身，宿主机服务用 `host.docker.internal`。

测试成功只证明普通 Chat Completions 请求可用；工具调用、视觉、Responses 等能力取决于服务商与模型。向量模型与重排模型是另外两块配置（`/embedding-config`、`/rerank-config`），见 [`生产部署手册.md`](生产部署手册.md) 第 5 节。
