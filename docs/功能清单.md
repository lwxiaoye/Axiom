# AXIOM 功能清单

| 项目 | 内容 |
| --- | --- |
| 用途 | 按当前源码归纳用户侧、管理侧与后端能力入口，供接手、验收和功能对比使用 |
| 状态 | 2026-09-19 按源码核对；列出的是代码里存在的入口，不代表每项已在目标环境配置或通过真实验收 |
| 不再包含 | 工作流编排 / 工作台、子智能体、我的智能体、发布审核、皮肤、对外 Agent API、独立文字识别服务、Java 系统管理（用户 / 角色 / 部门 / 租户 / 流程 / GPU 等）——均已随 2026-09-19 的删除或 Java 下线不复存在 |

> 实际可见入口受登录状态、管理员身份、`app_info` 上架记录的角色/部门 ACL、知识库 ACL 与平台配置影响。

## 1. 登录与账户（auth-api）

| 功能 | 可执行操作 | 代码入口 |
| --- | --- | --- |
| 登录 | 用户名 + 密码 + 图形验证码；AES 登录协议参数由前端构建期与 auth-api 共同约定 | `views/system/loginmini/MiniLogin.vue`，`auth-api/app.py` `/sys/login`、`/sys/randomImage/{key}` |
| 自助注册 | 带验证码的注册（`/sys/user/register`） | `MiniRegister.vue` |
| 个人资料 | 修改姓名、头像、邮箱、手机（`/sys/user/login/setting/userEdit`），头像经 `/sys/common/upload` | `views/peopleCenter/components/ProfileModal.vue` |
| 管理员 | 唯一内置管理员（`AXIOM_ADMIN_USER` / `AXIOM_ADMIN_PASSWORD`）；管理页可看用户列表（只读，`/sys/user/list`） | `AdminConsolePage.vue` 「用户」tab |
| 隐私边界 | 管理员看不到用户的会话、文件、知识库与个人技能（不存在即 404）；同一浏览器换人登录时本机状态按用户作用域清理 | agent-api 各 router 的归属校验 |

## 2. 主对话 `/center/chat`

| 功能 | 可执行操作 | 代码入口 |
| --- | --- | --- |
| 会话 | 新建、历史列表与搜索、置顶、重命名、删除；导航离开只断开订阅，后台 Run 继续 | `ThreadSelector.vue`，`/chat/threads*` |
| 模型 | 从平台名册（管理员配置，对全员生效）或个人覆盖中选择；会话内切换模型 | `ModelSelector.vue`，`GET /models`，`/chat/threads/{id}/model` |
| 发送与控制 | 发送、停止、重新生成、编辑历史消息并重发；运行中发送的消息默认入队，可重排或用于改向当前任务 | `ChatTab.vue`，`/chat/runs*`、`/chat/threads/{id}/queue*` |
| 执行过程 | 思考（Thought）、公开过程阐述、工具步骤、计划卡与任务协作面板、错误与终态 | `MessageList.vue`、`ThinkingReasoningStep.vue`、`TaskCollaborationPopover.vue` |
| 计划模式 | 先调查、追问、出计划，用户确认后执行；执行中可调整方向 | `agent_mode=plan`，`services/agent_harness/plan_*.py` |
| 深度研究 | 临时研究团队并行取证、集中核对、发表前核验，交付带引用的蓝框报告；可复制或导出 Markdown / Word / PDF | `agent_mode=research`，`services/agent_harness/research/`，`ResearchReportExportMenu.vue` |
| 人在环 | `ask_user_choice` 选择卡、计划确认卡、敏感工具审批卡（`approval.required` → `/gateway/approve|reject`） | `ChoiceQuestionCard.vue`、`QuestionCard.vue`，`routers/gateway.py` |
| 附件 | 上传文档与图片（`/chat/upload`）；文档解析进上下文，图片直接进多模态模型 | `AttachmentCard.vue`，`services/files/document_parse_service.py` |
| 联网搜索 | 开关式联网搜索（SearXNG + 平台重排模型，可选 Firecrawl 抓正文），来源面板可查 | `services/chat/tools/web.py`，`services/knowledge/web_search_service.py`，`SourcesPanel.vue` |
| 知识库问答 | 选择有权限的知识库参与回答，引用可查看 | `KnowledgeSelector.vue`，`services/chat/tools/knowledge.py` |
| @Skill | 在输入框以 `@` 选择自己可见的技能，本轮挂进沙箱执行 | `SkillSelector.vue`，`use_skill` 工具，`services/skills/skill_package_bridge.py` |
| bash 与文件工具 | 模型只见 `bash`（沙箱）与 `glob` / `read_file` / `write_file` / `edit_file`；产物经交付检查后进入我的文件 | `services/chat/tools/shell.py`、`workspace.py`，`services/sandbox/` |
| 浏览器工具 | 状态化浏览器与页面抓取（Playwright MCP 容器） | `services/chat/tools/browser.py` |
| 工作文件夹 | 在 + 菜单绑定一个个人文件夹，Agent 按权限读取、版本化编辑并把交付文件归入该文件夹 | `WorkFolderMenu.vue`，`workspace_folder_id`，`services/agent_harness/workspace_service.py` |
| 上下文压缩 | 上下文用量显示、手动压缩；超窗口前自动分段摘要 | `/chat/threads/{id}/context-usage`、`/compact`，`CompactionStep.vue` |
| 长期记忆 | 查看、编辑、删除记忆与个性化设置；模型只能提出候选，经治理后写入 | `MemoryDrawer.vue`，`/memories*`、`/personalization` |
| 旁路会话 | 右侧轻量侧聊（`side_chat=true`），不改写主会话来源 | `SideChatPanel.vue` |
| 反馈 | 对助手消息点赞/点踩 | `/chat/messages/{id}/feedback` |
| 连接器 | GitHub / Gmail / Outlook / IMAP 授权与资源范围的后端与组件仍在，但主对话入口开关为隐藏（`connectors: false`） | `mainChatFeatureVisibility.ts`，`routers/connectors.py` |

## 3. 预置智能体（智能体广场 `/center/agent`）

三个智能体全部代码内置，由 agent-api 启动时幂等写入 `app_info` 上架记录；用户不自建智能体。

| 智能体 | 路由 | 能力 | 代码入口 |
| --- | --- | --- | --- |
| 校园百事通 | `/center/chat/campus` | 只用已发布快照绑定的知识库与学校官网白名单回答（`search_knowledge` / `search_web`），依据不足即拒答；可发图片、终答可展示有来源的配图 | `services/chat/builtin_assistants/campus_services/`，前端 `builtinAssistants/campusServices/` |
| 演示文稿助手 | `/center/chat/ppt` | 每轮强制加载内置 `ppt-studio` 技能制作并交付演示文稿；不开放 `@`、计划模式、深度研究 | `builtin_assistants/presentation/`，`services/skills/builtin/ppt-studio/` |
| 面试助手 | `/center/chat/interview` | 依据简历与岗位 JD 出题、追问、提示、跳题、暂停续练；整场结束后给百分制报告并可下载 | `builtin_assistants/interview/`，`app/api/interview.py`，`interview_models.py` |

上架记录的角色/部门 ACL 决定谁能看到并使用；停用记录后该智能体不可见。当前没有编辑上架记录的管理页面。

| --- | --- | --- |

## 5. Skill 广场 `/center/skill`

| 功能 | 可执行操作 | 代码入口 |
| --- | --- | --- |
| 个人技能 | 直接编写（名称、说明、SKILL.md 正文）或 zip 导入；编辑、删除、启停；查看版本与内容 | `SkillSquare.vue`，`routers/agent_skill.py` `/skill/*` |

## 7. 管理配置 `/admin`（仅管理员）

| 板块 | 内容 | 接口（`/agent-api` 前缀） |
| --- | --- | --- |
| 对话模型 | 名册：可添加多条模型（名称、OpenAI 地址、Anthropic 地址、模型 ID、密钥），设默认、启停、拖动排序、逐条测试与批量测速；对全员生效 | `GET/PUT /model-connection`，`POST /model-connection/test`、`/test-speed` |
| 向量模型 | 地址、模型、密钥、维度；更换后需重建知识库索引；同页下方为重排模型 | `/embedding-config*`，`/rerank-config*` |
| 联网搜索 | 启用开关、SearXNG 引擎、结果重排等 | `/platform-config/web-search*` |
| 校园百事通 | 选择对话模型、编辑草稿、校验、发布；发布记录与回滚 | `/campus-assistant/admin/*` |
| 用户 | 内置管理员 + 自助注册用户列表（只读） | auth-api `GET /sys/user/list` |

所有密钥以 Fernet 密文入库（主密钥 `CONNECTOR_SECRET_KEY`），接口只回 `has_api_key`，留空表示保持原密钥。

## 8. 个人模型配置 `/center/models`

任何登录用户可选填一条自己的 OpenAI 兼容连接（地址、模型、密钥），优先于平台名册；关闭后回到平台默认模型。见 [`模型连接配置.md`](模型连接配置.md)。

## 使用说明

1. 三个预置智能体的可见性由 `app_info` 上架记录的 ACL 决定；校园百事通还要求管理员已发布配置。
2. 对外展示或验收时，按管理员配置（对话 / 向量 / 重排 / 联网搜索）、沙箱与浏览器容器是否运行、学校知识是否入库逐项确认。
3. 新增、调整或下线面向用户的功能时同步更新本清单；不要把已删除的功能重新写回来。
