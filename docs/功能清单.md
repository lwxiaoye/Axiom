# AXIOM平台功能清单

| 项目 | 内容 |
| --- | --- |
| 用途 | 汇总当前源码提供的业务功能入口，供产品介绍、项目验收和功能对比使用。 |
| 状态 | 源码功能清单；不代表每项已部署、已配置或通过真实验收。 |
| 更新日期 | 2026-09-11 |

> 实际可见功能受登录、角色、组织和权限配置影响。

## 1. 用户侧 AI 综合平台

| 功能模块 | 功能 | 可执行操作 |
| --- | --- | --- |
| 主对话 | AI 对话 | 新建会话、选择模型和执行方式、发送消息、停止生成、继续未完成任务、编辑或重新发送消息。 |
| 主对话 | 会话历史 | 查看、切换和删除会话；按分组浏览历史；恢复草稿和上下文。 |
| 主对话 | 任务执行过程 | 查看思考过程、任务计划、工具使用、子智能体、执行状态和生成结果；支持追问及选择反馈。 |
| 主对话 | 计划与协作 | 创建和查看任务步骤；在执行中调整任务方向；查看协作任务进度。 |
| 主对话 | 消息排队与改向 | 运行中发送的消息默认入队，支持重排；可将指定消息用于调整当前任务方向。 |
| 主对话 | 深度研究 | 临时研究团队分工取证、查看检索来源、交付带引用的蓝框报告；可主动复制或导出 MD/DOCX/PDF。完成或部分交付后下一轮回到普通模式。 |
| 主对话 | 文件与多模态输入 | 上传文档、图片等附件，并作为对话内容进行分析。 |
| 主对话 | 工作文件夹 | 在输入框 + 右侧新建或选择个人文件夹、上传素材；绑定后 Agent 可按权限读取、版本化编辑并将生成交付文件归入该文件夹。 |
| 主对话 | 知识库问答 | 选择有权限的知识库进行问答，并查看引用内容。 |
| 主对话 | Skill 与智能体使用 | 通过 `@` 选择智能体或 Skill，并在当前对话中使用。 |
| 主对话 | 外部服务连接 | 后端保留连接器授权及资源范围能力；当前主对话连接器管理按钮隐藏，不能作为已开放的用户操作入口介绍。 |
| 主对话 | 长期记忆 | 查看和管理个人偏好及长期事实。 |
| 主对话 | 生成内容交付 | 预览文本、图片、Office、PDF、网页和表格等结果；下载或保存至“我的文件”。 |
| 内置助手 | 校园百事通 | 独立页面基于已发布学校知识库与官网范围回答，可接收图片并展示有来源的配图。 |
| 内置助手 | 演示文稿助手 | 独立页面使用已启用的第一方 ppt-studio 制作与交付演示文稿。 |
| 内置助手 | 面试助手 | 按简历与岗位 JD 进行文字问答、追问、提示、跳题与暂停续练；过程中只展示问答，整场结束并保存复盘后展示百分制报告和下载入口。评分保存首答与辅助作答的区别，当前页面不提供逐题反馈或重答菜单。 |
| 智能体广场 | 智能体发现 | 浏览、搜索、分类筛选和查看智能体能力；直接发起对话。 |
| 我的智能体 | 个人智能体管理 | 查看个人可用智能体；进入配置、运行和管理页面。 |
| 我的智能体 | 运营与对话记录 | 在管理权限范围内查看应用运营统计、会话记录、运行状态和反馈。 |
| Skill 广场 | Skill 发现与使用 | 浏览 Skill、查看详情、安装或在对话中使用。 |
| 我的知识库 | 知识库入口 | 浏览有权限的知识库，并进入文档管理。 |
| 我的文件 | 文件管理 | 创建、改名和删除文件夹；上传、移动、预览、下载、删除和保留文件。 |
| 我的文件 | 版本与演示文稿 | 查看、下载和恢复文件历史版本；重新编译修改后的演示文稿。 |

## 2. 工作台与智能体应用

| 功能模块 | 功能 | 可执行操作 |
| --- | --- | --- |
| 工作台 | 应用管理 | 创建、编辑、复制、删除、排序和筛选智能体应用；查看运行和发布状态。 |
| 工作流编排 | 可视化画布 | 拖拽节点、连接流程、配置变量及输入输出；保存草稿并检查流程。 |
| 工作流编排 | AI 对话节点 | 配置模型、提示词、历史对话、文件输入和 Skill 引用。 |
| 工作流编排 | 知识增强 | 配置知识库搜索、引用合并、检索方式、重排和引用上限。 |
| 工作流编排 | 流程控制 | 配置问题分类、条件分支、变量更新、文本信息提取和指定回复。 |
| 工作流编排 | 工具与接口调用 | 配置 HTTP 工具、MCP 工具、请求参数、鉴权信息、动态输入输出，并在线测试。 |
| 工作流调试 | 调试运行 | 输入测试变量或附件，查看节点执行、错误和中间结果。 |
| 工作流发布 | 发布与权限 | 发布或下线应用；设置应用访问范围、角色和部门权限。 |
| 工作流发布 | 更新与版本回滚 | 检查草稿与线上版本差异、更新发布、查看版本及回滚；保存草稿不直接替换线上版本。 |
| 智能体管理 | 管理员治理 | 在管理员权限下查看应用详情、运行统计、版本差异和审计；执行转移负责人、停用、恢复、回滚等治理操作。 |
| 工作流运行 | 应用对话 | 在独立应用中进行流式对话、填写交互表单、查看图表和文件结果。 |
| 工作流复核 | 运行复核 | 查看运行摘要、状态、输出和相关执行信息。 |
| 展示配置 | 页面皮肤 | 管理智能体及主对话的展示皮肤和预览效果。 |

## 3. 知识、技能、连接器与文件服务

| 功能模块 | 功能 | 可执行操作 |
| --- | --- | --- |
| 知识库 | 知识库管理 | 新建、编辑、删除和查询知识库；维护访问范围。 |
| 知识库 | 文档管理 | 上传、查看、删除和重新处理文档；查看解析与入库状态。 |
| 知识库 | 内容维护 | 查看、编辑和删除文档分块；维护问答和引用内容。 |
| 知识库 | 检索测试 | 按知识库检索内容并查看匹配结果和引用，用于调优和验收。 |
| 知识库 | 智能体关联 | 为智能体绑定可检索的知识库，并控制访问权限。 |
| 知识库 | 分级权限与后台管理 | 用户入口按可读、可编辑、可管理权限展示操作；后台管理入口独立使用管理接口。 |
| 知识库 | 原文与运营统计 | 下载单份原文或批量 ZIP，查看当前库存、区间统计和知识库/文档排行；统计数据依赖 Java 管理接口。 |
| Skill | Skill 管理 | 查询、上传、安装、查看详情、启停或卸载 Skill，并查看安装记录。 |
| 可执行技能 | 专用技能使用 | 使用文档、表格、演示文稿等专用技能完成任务。 |
| 连接器 | 第三方授权 | 通过授权或令牌连接外部服务。 |
| 连接器 | 资源授权范围 | 选择账号、开启或关闭连接器、设置资源白名单和断开连接。 |
| 文件服务 | 个人文件空间 | 管理个人文件、文件夹、文件配额和文件所属范围。 |
| 文件服务 | 文件预览与交付 | 预览、下载各类文件；保存生成结果；保留或恢复历史版本。 |
| 执行环境 | 隔离执行 | 在隔离环境中完成文件处理、代码执行和内容生成。 |

## 使用说明

1. 本清单仅描述当前功能，不代表所有功能对每个用户均可见或可用。
   三个内置助手需要管理员登记同路径的 external 应用并配置权限；代码不会自动向广场补卡。工作文件夹仅在普通主对话开放。
2. 需要对外展示、上线或验收时，应按角色权限、部署环境、外部服务授权及学校数据准备情况进行确认。
3. 新增、调整或下线面向用户的功能时，应同步更新本清单。
